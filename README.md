# ChessGui
ChessGui is a C# Windows Forms application that provides a graphical user interface for playing chess. It allows users to play against an AI opponent or another player, with features such as move validation, timers, and a visual representation of the chessboard.

How to play:
1. Launch the ChessGui application.
2. Choose to play against the Yourself or another player.
3. if another player, select Host to create a game and connect to the other player.
4. The host selects the color of the pieces (white or black) and starts the game.
5. White starts and play the game.
